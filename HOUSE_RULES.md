## 1. Постоянные правила владельца

### R1. Временные файлы — в папке проекта

1. Свои временные файлы (скрипты, рендеры, загрузки, выводы прогонов) клади в `.work/tmp/` этого проекта — папка
   `/.work/` в `.gitignore`.
2. В команде, которая создаёт временные файлы сама, задавай `TEMP`/`TMP` явно: среда агента подменяет их своим
   оболочкам, и `env` из `.claude/settings*.json` до них не доходит.
3. `F:\Temp` (пользовательский `TEMP` машины) — разрешённое место: там черновик среды агента.
4. `D:\Temp` — папка владельца: не пиши туда, не читай и не удаляй.
5. Доделал работу — убери за собой её временные файлы.
- **Исключение:** нет.

### R5. JavaScript — только в формате `.mjs`

1. Каждый JS-файл проекта вне HTML-страницы — модуль `.mjs` (`import`/`export`), не `.js` и не `.cjs`.
2. Код внутри HTML-страницы — `<script type="module">`.
- **Исключение:** файл, формат которого диктует чужой инструмент (конфиг, который тот читает только как `.js`/`.cjs`), —
  с причиной в комментарии.

[OWNER] 2026-11-16 15:29 +03:00 · чат первой сессии: «для JS предпочтителен формат mjs»

### R6. Только Windows — без WSL

1. Инструменты выбирай с нативной сборкой под Windows (exe, Node, Python для Windows).
2. WSL не ставь и не предлагай; инструмент, которому нужен Linux, — не вариант.
- **Исключение:** нет.

### R7. Страница самодостаточна

1. `kalculator/index.html` не загружает ни одного файла, кроме себя: иконка, шрифты и данные живут внутри страницы
   (иконку вписывает `node tools/embed-icon.mjs`).
2. Тексты страницы не отсылают читателя к файлам и каталогам репозитория (`researches/`, `ideas/` и т. п.); источник числа
   называется в самой странице — автор, работа, год.
3. Проверка: `node tools/ui-run.mjs` — случаи «self-contained» (запросов, кроме самой страницы, нет; значок вкладки — data
   URI; в видимом тексте нет `researches/`).
- **Исключение:** ссылка на публичный репозиторий в подвале страницы.
