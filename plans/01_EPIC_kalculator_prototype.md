## Вектор цели

**Achieve:** человек открывает `kalculator/index.html` с диска, вводит место, желания и свой принтер — и получает
рекомендованные параметры турбины KATAK, её характеристики и STL-файлы ротора, оси и носа, которые нарезаются
слайсером без ошибок.

## Критерии приёмки

1. Ситуация. Новый пользователь открыл страницу без интернета.
   Действие. Пользователь нажимает «Рассчитать» со значениями по умолчанию.
   Результат. Страница показывает мощность, выработку за год, обороты и нагрузку на вал; ни одной ошибки в консоли.
   Проверка. `node tools/ui-run.mjs` — сценарий «по умолчанию» pass, снимок в отчёте прогона.
2. Ситуация. Ротор 300 мм, сопло 0,4 мм, детализация «средняя».
   Действие. Пользователь скачивает STL ротора.
   Результат. Файл открывается в слайсере как одна деталь без дыр.
   Проверка. `node kalculator/test.mjs` печатает «mesh closed: every edge used twice» для ротора, оси и носа; нарезка
   OrcaSlicer из CLI — без ошибок.
3. Ситуация. Пользователь выбрал английский язык вверху справа.
   Действие. Пользователь переключает язык.
   Результат. Все надписи страницы на английском, числа с точкой.
   Проверка. `node tools/ui-run.mjs` — сценарий «язык» сверяет, что ни одной русской буквы не осталось в видимом тексте.
4. Ситуация. Сопло 0,4, слой 0,2, просимая стенка 1,0 мм.
   Действие. Пользователь нажимает «Рассчитать».
   Результат. Страница показывает стенку 1,264 мм = 3 линии (формула `researches/02` §2).
   Проверка. `node kalculator/test.mjs` — случай «стенка под сопло» pass.

## Риски

- (a) Пересекающиеся тела в одном STL: слайсеры объединяют замкнутые оболочки — проверяется нарезкой; если нет — булево
  объединение сетки, это большой кусок работы.
- (b) Нависания лопасти при печати: генератор должен предупреждать; разбиение ротора на части — вне первой версии.
- (c) Физика спиральной турбины спорная (заявления производителя против независимых замеров) — показываем числа
  независимых источников и пишем это на странице.
