## Вектор цели

**Achieve:** у каждого поля страницы перед подписью стоит кнопка (i); наведение мыши на компьютере или касание на телефоне
открывает окно с пояснением: что задаёт поле, какие у него варианты, на какую величину расчёта или геометрии влияет
каждый вариант и при каких условиях какой вариант оптимален.

## Решение к реализации `[AI]`

1. В словарь `I18N` добавить блок `info` на каждое поле (RU и EN, академический регистр, без частых тире): определение;
   варианты и их влияние; оптимум с условиями; источник (раздел `researches/01–03`). Числа — только из конспектов.
2. Кнопка (i) — `<button class="info" aria-label="…">i</button>` перед подписью; окно — один общий элемент, позиционируется
   у кнопки; на компьютере открывается по `mouseenter`/`focus`, на телефоне по касанию, закрывается касанием вне окна и Esc.
3. Проверка: `tools/ui-run.mjs` — у каждого поля есть кнопка (i), окно открывается наведением и касанием (эмуляция телефона),
   в окне есть строка «оптимум»; голос страницы — `kaif-voice-lint check`.
