# Идея 06 — крупные города мира по часовым поясам с профилем ветра по пятну 300 км

> **Создан:** 2026-11-16 (по слову владельца в чате) · **Родитель:** `ideas/04`; шаг 1 страницы (параметры площадки) ·
> **Статус:** ✅ одобрена владельцем (его собственное пожелание) · 🔲 нужна разведка источника данных о ветре · **Вовне:** —

## Слово владельца (дословно)

> «в выборе местности можешь добавить основные крупные города мира - как по часовым поясам, и по ним по этим регионам в
> усреднении по пятну 300 КМ вокруг этого города можно сразу брать профиль ветра»

— владелец, чат первой сессии, 2026-11-16 16:29 +03:00

## Вектор цели

**Achieve:** пользователь выбирает ближайший крупный город своего часового пояса, и страница заполняет среднюю скорость
ветра, её высоту, параметр Вейбулла k и тип местности средними значениями по кругу радиусом 300 км вокруг города.

## Что нужно до кода (три двери: числа только из источника)

1. Разведка источника: Global Wind Atlas (средняя скорость на 10/50/100 м, параметры Вейбулла, сетка 250 м), реанализ
   ERA5 (среднемесячные скорости на 10 м), NASA POWER; лицензия данных для открытого проекта (MIT-код + данные с
   атрибуцией).
2. Список городов: по одному-два крупнейших города на каждый часовой пояс (≈ 40–60 городов), координаты из открытого
   источника.
3. Сценарий подготовки данных `tools/wind-presets.mjs`: для каждого города — среднее по кругу 300 км, запись в таблицу
   `kalculator/wind-presets.json` с источником и датой выгрузки; таблица вшивается в страницу.
4. Поле «Регион (город)» на шаге 1 с поиском; выбор заполняет поля, пользователь может их изменить.
