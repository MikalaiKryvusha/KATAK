# Разведка 04 — формы носового обтекателя: стрела лука, оживало, Хаак, степенные профили

> **Создан:** 2026-11-16 · **Родитель:** `ideas/10_arrow_like_fairing_shape.md` · **Статус:** ✅ первый круг · **Вовне:** выбор профиля — владельцу.

**Метки достоверности** (как в `researches/01`): без метки — цитата источника; **[РАСЧЁТ]** — мой вывод или численная
проверка (скрипт описан в §6); **[ОЦЕНКА]** — инженерное суждение без прямого источника.

## Вывод

Форма, которую описал владелец («сразу тоненькое, потом гипербола, потом выравнивание на прямую»; «тонкий нос, широкая
база, два перегиба»), в стрельбе из лука называется **вогнутым наконечником** (*concave point*). Продавцы пишут о
спортивных наконечниках TopHat LL Apex: «aggressive concave shaped tip for straighter target entry and lesser glance outs
in crowded targets» [6]. О стальных полевых наконечниках 3Rivers: «with their concave shape are easier pulling out of
targets» [8]. Рядом стоят тонкие «pin points» и толстые «bullet points» [5]. Пару ему составляет выпуклый наконечник
(TopHat «Convex») [7]. Как кривая это **гусёк** (англ. *ogee*, лат. *cyma recta*), а в зодчестве — **килевидная арка**
(*ogee arch*). С оживалом (*ogive*) его путать нельзя: в статье [3] стоит пометка «Distinguish from Ogive». Определение ogee: «a serpentine or extended S shape (sigmoid)… a double curve… as a result of a point of
inflection from concave to convex» [3]. Гусёк по-русски — профиль, у которого «в верхней части выкружка (вогнутая часть
в четверть окружности), а внизу выпуклая» [4]. В справочнике ракетных обтекателей такой формы нет [1][2]. Там все формы
либо выпуклые (конус, эллипсоид, оживала, парабола, Хаак), либо раструбом без касания базы (степенной ряд с n > 1).
Гипотеза главного агента подтверждается: у носа вогнутый участок, у базы выпуклый, база переходит в цилиндр по
касательной. Оговорка про «два перегиба»: у острого гуська **одна** математическая точка перегиба и два видимых излома
(где игла начинает расширяться и плечо у базы). **Ровно две** точки перегиба получаются, если иглу затупить маленькой
сферой (выпукло → вогнуто → выпукло, §3.2). Для печати иглу затуплять всё равно нужно. Для сопротивления форма почти не
важна. У нас число Маха ≤ 0,07, а ниже M 0,8 «the nose pressure drag is essentially zero for all shapes»; главное — трение,
оно зависит от смачиваемой площади и от разрывов формы [2]. У гуська смачиваемая площадь на 30 % меньше, чем у эллипсоида
той же длины [РАСЧЁТ, §2.1].

## 1. Наш поток — почему форма носа мало значит

- Число Маха: M = V/a, a = √(1,4·287·293) ≈ 343 м/с при 20 °C. Для V = 3…25 м/с M = 0,009…0,073 **[РАСЧЁТ]**.
- Число Рейнольдса по диаметру базы: Re_D = V·D/ν, ν ≈ 1,5·10⁻⁵ м²/с (`researches/01` §2.4). При D = 30…150 мм
  Re_D ≈ 6·10³…2,5·10⁵ **[РАСЧЁТ]**: пограничный слой ламинарный или переходный.
- Источник о дозвуковых носах: ниже M 0,8 сопротивление давления носа «essentially zero for all shapes». Главный фактор —
  трение, которое «largely dependent upon the wetted area, the surface smoothness… and the presence of any
  discontinuities in the shape». Для чисто дозвуковых ракет «a short, blunt, smooth elliptical shape is usually best» [2].
- **[ОЦЕНКА]** Наш обтекатель стоит на оси в 10–100 мм перед ротором, а в зазоре — стойка переднего подшипника (`ideas/04`).
  Значит, за базой носа нет цилиндра того же диаметра: торец базы плоский, и донное сопротивление этого торца и стойки
  больше разницы между профилями. «Касание цилиндра базы» в таблице ниже — свойство формы. Аэродинамически оно работает,
  только если база носа почти упирается в ступицу ротора.
- Измерений сопротивления S-образных (вогнуто-выпуклых) носов на малых скоростях я **не нашёл**.

## 2. Кандидаты

Обозначения всех формул: x — расстояние от вершины, 0 ≤ x ≤ L; r — радиус; L — длина носа; R — радиус базы [1]. На
странице `nose_ratio` = L/(2R), значит L/R = 2·nose_ratio; допустимый диапазон 0,6–1,0, по умолчанию 0,8.

| № | Название (RU / EN) | r(x) | Касается цилиндра базы | Точек перегиба | Где применяется | Сопротивление на малых скоростях |
|---|---|---|---|---|---|---|
| 1 | Конус / Conic | `r = R·x/L` [1] | нет: излом под углом arctan(R/L) [1] | 0 | — | излом на стыке — место отрыва; `researches/01` §6.8 не советует острый конус [ОЦЕНКА] |
| 2 | Эллипсоид / Elliptical | `r = R·√(x(2L − x))/L` [1] | да («tangent base») [2] | 0 | модельные ракеты, дозвуковой полёт [2]; сейчас по умолчанию на странице | для чисто дозвуковых «usually best» [2]; самая большая смачиваемая площадь из списка [РАСЧЁТ] |
| 3 | Касательное оживало / Tangent ogive | `ρ = (R² + L²)/(2R)`; `r = √(ρ² − (L − x)²) + R − ρ` (в [1] записано `√(ρ² + x(2L − x) − L²)`, это то же) | да («the rocket body is tangent to the curve of the nose cone at its base») [2] | 0 | ракеты, снаряды, пули [ОЦЕНКА] | данных для M < 0,1 нет; по [2] трение решает, площадь на 9 % меньше эллипсоида [РАСЧЁТ] |
| 4 | Секущее оживало / Secant ogive | `α = arctan(R/L) − arccos(√(L² + R²)/(2ρ))`; `r = √(ρ² − (x − ρ·cos α)²) + ρ·sin α`, ρ ≥ ρ касательного [1] | нет («will not be tangent») [2] | 0 | — | излом у базы [2] |

## 3. Формула гуська, готовая к коду

### 3.1 Острый гусёк (две дуги)

Условие: **L > R** (на странице nose_ratio > 0,5; диапазон поля 0,6–1,0 подходит). Параметр **t** — доля длины от вершины до
точки перегиба, 0 < t < 1, **по умолчанию t = 0,5**. Тогда точка перегиба лежит в (L/2, R/2), а каждая половина — касательное
оживало половинного размера: вершинная перевёрнута, базовая прямая **[РАСЧЁТ]**.

```
K  = (L² + R²) / (2R)          // радиус касательного оживала той же длины и базы
ρ1 = t·K,  ρ2 = (1 − t)·K       // радиусы вогнутой (у вершины) и выпуклой (у базы) дуг

0 ≤ x ≤ t·L :  r = ρ1 − √(ρ1² − x²)                      // центр дуги (0, ρ1) — снаружи тела
t·L ≤ x ≤ L :  r = R − ρ2 + √(ρ2² − (L − x)²)             // центр дуги (L, R − ρ2) — внутри тела
```

Почему перегиб на хорде **[РАСЧЁТ]**. Касание двух дуг друг друга с концами, параллельными оси, требует
tg 2φ₁ = tg 2φ₂. Здесь φ₁, φ₂ — наклоны хорд половин, поэтому точка перегиба лежит на прямой от вершины (0, 0) к краю базы
(L, R). Отсюда семейство с одним параметром t.

Свойства, проверенные численно **[РАСЧЁТ]**: r(0) = 0; r(L) = R; наклон у базы 0 (касание цилиндра); наклон у вершины 0
(игла касается оси — «сразу тоненькое»); в x = tL r = tR, наклоны слева и справа равны (стык гладкий по касательной,
кривизна меняет знак скачком); профиль монотонный; ровно одна точка перегиба. Самый крутой наклон образующей — в точке
перегиба: угол 2·arctan(R/L), то есть 64° к оси при nose_ratio 0,8. При печати вершиной вверх каждый слой меньше
предыдущего, нависаний нет.

В соглашении функции `shape(u)` из `nose()` в `kalculator/index.html` (u = 0 у базы → 1 у вершины, ответ r/R,
lam = L/R = 2·nose_ratio):

```js
// Ogee nose (researches/04 §3.1): two tangent arcs, inflection at (t·L, t·R). Needs lam > 1. [NOT-TESTED]
const ogee = (u, lam, t = 0.5) => {
  const K = (lam * lam + 1) / 2, a = t * K, b = (1 - t) * K, x = lam * (1 - u);
  return x <= t * lam ? a - Math.sqrt(Math.max(0, a * a - x * x))
                      : 1 - b + Math.sqrt(Math.max(0, b * b - (lam - x) ** 2));
};
```

Численно эта запись совпадает с формулой в x до 0 при lam = 1,2 / 1,6 / 2,0 **[РАСЧЁТ]**.

**Риск для печати [ОЦЕНКА]:** острая игла тоньше линии сопла. При t = 0,5 на 10 % длины радиус всего 0,015 R: для R = 25 мм
это 0,4 мм, то есть игла Ø 0,8 мм длиной 4 мм. Сопло 0,4 такую не напечатает, слайсер её срежет или сделает каплю. Поэтому
в генератор лучше брать вариант 3.2.

### 3.2 Затуплённый гусёк (две точки перегиба)

Сфера радиуса r_n на оси касается вогнутой дуги снаружи (расстояние между центрами ρ1 + r_n) **[РАСЧЁТ]**:

```
x_c = √(2·ρ1·r_n + r_n²)        // центр сферы на оси
x_t = x_c · ρ1 / (ρ1 + r_n)      // точка касания сферы и вогнутой дуги
x_a = x_c − r_n                  // новая вершина

x_a ≤ x ≤ x_t :  r = √(r_n² − (x − x_c)²)                 // сфера
x_t ≤ x ≤ L   :  как в 3.1
```

Проверка численно **[РАСЧЁТ]**: монотонный профиль, r(L) = R, ровно две точки перегиба — в x_t и в tL. Например, при
L/R = 1,6, t = 0,5, r_n = 0,03 R они лежат в 0,141 L и 0,5 L. Нос короче на x_a: на 12,7 % при r_n = 0,03 R и на 17,0 % при
r_n = 0,06 R. Чтобы вернуть заданную длину, растяните профиль вдоль оси: x ↦ (x − x_a)·L/(L − x_a). Растяжение вдоль оси
сохраняет r(L) = R, касание базы и число перегибов. **Параметр по умолчанию [ОЦЕНКА]:** r_n = max(ширина линии w,
0,03·R), то есть ≈ 0,45 мм для сопла 0,4 (`researches/02` §1). Вершина тогда не тоньше одной линии.

### 3.3 Гладкая альтернатива (без скачка кривизны)

Сигмоида Кумарасвами при a = b = 2 [10]: `r/R = 1 − (1 − u²)² = 2u² − u⁴`, u = x/L. Тут r(0) = 0, r(1) = 1, наклон у базы 0,
одна точка перегиба в u = 1/√3 ≈ 0,577 **[РАСЧЁТ]**. Это один многочлен без параметров формы. Игла у вершины такая же
тонкая, как в 3.1, затупление нужно и здесь.

## 4. Находка для кода: «оживало» на странице совпадает с «эллипсоидом»

Сейчас в `nose()` (`kalculator/index.html`, строка с `p.nose_shape === 'ogive'`):

```js
if (p.nose_shape === 'ogive') { const L = 1, rho = (1 + L * L) / 2, x = 1 - u; return Math.sqrt(Math.max(0, rho * rho - (L - x) * (L - x))) + 1 - rho; }
```

При L = 1 получается ρ = 1 и L − x = u, так что выражение равно √(1 − u²) — ровно ветке эллипсоида `Math.sqrt(1 - u*u)`.
Численно разница ≤ 2,2·10⁻¹⁶ на всём u ∈ [0, 1] **[РАСЧЁТ]**. Касательное оживало зависит от L/R, а здесь оно посчитано
для L = R и потом растянуто по оси; при растяжении дуга окружности стала дугой эллипса. Верная запись в том же
соглашении (u = 0 у базы → 1 у вершины, lam = L/R):

```js
const rho = (1 + lam * lam) / 2; return Math.sqrt(Math.max(0, rho * rho - (lam * u) ** 2)) + 1 - rho;
```

Численно она совпадает с формулой №3 из [1] до 4,4·10⁻¹⁶ при lam = 1,2 / 1,6 / 2,0, и r(вершина) = 0 **[РАСЧЁТ]**.
Код я не правил (границы задания); это дефект для `bugs/`.

## 5. Чего я не подтвердил

- Точный чертёж профиля «concave»-наконечников TopHat и 3Rivers. Источники — описания продавцов, а их слова о «straighter
  entry» — реклама, а не испытания. Страницы Lancaster о TopHat Classic 3D и LL Apex ответили 429; описание LL Apex
  взято у Abbey Archery [6], Classic 3D — только из выдержки поиска [7].
- Оригинал Crowell (1996) не открыт: web.archive.org недоступен этому инструменту. Его текст цитирую по копии статьи
  Википедии 2007–2008 гг., которая ссылается на Crowell [2].
- Таблица рангов сопротивления в Википедии — картинка; чисел из неё я не снял.
- Измерения сопротивления S-образных носов при M < 0,1 не найдены. Строки «сопротивление» для №8–11 — оценка.
- Средневековые «needle bodkin» (длинная тонкая игла, переходящая во втулку) — тоже похожий образ, но видел только
  выдержки из зеркал статьи Википедии [9]; типологию Jessop не проверял.
- Что владелец имел в виду под «двумя перегибами» — две математические точки перегиба (вариант 3.2) или два видимых
  излома (вариант 3.1), — решает он по картинке.

## 6. Как проверены числа

Скрипты лежали во временной папке сессии (вне проекта): `check_profiles.mjs` и `check_blunt_ogee.mjs`. Для каждого профиля
они считают r(0), r(L), монотонность, точки перегиба (смена знака второй разности на 20 000–40 000 точках без 0,5 % у
концов), наклоны у вершины и у базы, смачиваемую площадь и объём; там же сравнение «оживало = эллипсоид». Главному агенту
стоит повторить проверку рисунком (§2 задания идеи 10).
