## 2. Двоичный STL

Формат ([Wikipedia: STL](https://en.wikipedia.org/wiki/STL_(file_format)) · [Kaitai Struct: STL](https://formats.kaitai.io/stl)):

| Смещение | Размер | Что |
|---|---|---|
| 0 | 80 байт | заголовок; **не должен начинаться со слова `solid`** — иначе программы примут файл за текстовый STL |
| 80 | 4 байта, uint32 LE | число треугольников N |
| 84 + 50·i | 12 байт, 3 × float32 LE | нормаль |
| | 36 байт, 9 × float32 LE | три вершины |
| | 2 байта, uint16 | «attribute byte count», обычно 0 |

Размер файла = 84 + 50·N байт. Единиц в формате нет; слайсеры считают числа миллиметрами — KATAK пишет миллиметры.
Порядок вершин — против часовой стрелки, если смотреть снаружи (нормаль по правилу правой руки наружу).

**Печатная сетка должна быть замкнутой** (watertight, 2-manifold): каждое ребро принадлежит ровно двум треугольникам, с
противоположным обходом. Это проверяет `kalculator/test.mjs` (подсчёт рёбер) и, сверх того, нарезка слайсером из CLI
(OrcaSlicer/PrusaSlicer на машине есть — `HOUSE_RULES.md` досье).

**В браузере:** `ArrayBuffer(84 + 50·N)` + `DataView.setFloat32(…, true)` → `Blob` → `URL.createObjectURL` → ссылка с
атрибутом `download` — файл сохраняется без сервера.

## 4. Языки

- Словарь `{ ru: {…}, en: {…} }`, разметка несёт ключи `data-i18n`; язык — из `localStorage` (в `try/catch`), иначе из
  `navigator.language`, иначе английский.
- Выбор языка — вверху справа (`GOAL.md`), как в KEINKT; новый язык добавляется одним блоком словаря.
- Числа форматируются `Intl.NumberFormat(lang)` — запятая в русском, точка в английском.
