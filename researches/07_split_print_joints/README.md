## 1. Вывод

Ротор режется на этажи ядра (поперёк оси) и юбки (по окружности r_cut в виде сверху). Все детали собираются одним
движением вдоль оси со стороны носа, в порядке «задний этаж → передний этаж → юбки». Шов юбки с ядром — гребёнка ласточкиных
хвостов, вычерченная в виде сверху вдоль окружности r_cut и выдавленная вдоль оси: зубцы держат юбку от центробежной силы
механически, клей заполняет зазор, тонкая полка под швом служит упором. Этажи ядра соединяются буртиком ступицы, их центрирует
стальная ось. Сборка вдоль оси возможна, пока юбка охватывает не больше ≈ 120° витка: на Ender 3 это 5 деталей до
280–300 мм; для большего ротора юбка режется на сегменты (8 деталей до 440 мм).

## 3. Что показал расчёт на ядре KATAK

1. **Узкое место — длина ротора** (≈ 0,9·D): ядро упирается в высоту печати раньше, чем юбки в ширину стола
   (`design/split/build-split-page.mjs`).
2. **Сборка вдоль оси** (`.work/tmp/assembly.mjs`, одноразовый): лопасти стоят друг за другом по витку через треть оборота.
   Точка юбки заблокирована, если в том же угле и на том же радиусе есть материал другой лопасти перед ней (сборка спереди)
   или за ней (сборка сзади). Доля заблокированной юбки при r_cut = 105 мм:

| D, мм | Юбка охватывает | Спереди | Сзади |
|---|---|---|---|
| 260 | 77° | 0 % | 0 % |
| 280 | 100° | 0 % | 0 % |
| 300 | 120° | 1,2 % | 0,5 % |
| 320 | 138° | 3,2 % | 12,9 % |
| 340 | 153° | 5,4 % | 21,9 % |

   Вывод: юбка вставляется вдоль оси спереди целиком, пока она охватывает не больше ≈ 120° витка.
3. **Нормаль лопасти** во всех точках имеет осевую составляющую одного знака: подветренная сторона везде смотрит назад по
   оси. Поэтому полка на подветренной стороне ядра встречает юбку, которая движется вдоль оси спереди.

## 4. Профиль сочленения

1. **Гребёнка в виде сверху.** Шов юбки в виде вдоль оси — окружность r = r_cut. Вдоль неё чертится гребёнка ласточкиных
   хвостов (зубцы от ядра в юбку), и граница выдавливается вдоль оси сквозь лопасть. Каждая точка лопасти принадлежит ядру
   или юбке по своему положению в виде сверху; лопасть над своим следом однозначна, поэтому разрез делается в координатах
   лопасти (вдоль витка × вдоль размаха).
2. **Стенки зубцов вертикальные** (параллельны оси): сборка — прямое движение вдоль оси; ротор печатается стоя, поэтому в
   слайсере это вертикальные стенки без нависаний. Высота клеевой стенки = толщина лопасти / |n_z| — больше самой стенки.
3. **Зазор под клей** на стенках зубцов — поле страницы, по умолчанию 0,2 мм `[AI]` (`researches/02` §6: скользящая посадка
   0,15–0,4 мм); пробник — отдельная деталь в выгрузке.
4. **Упор** — полка толщиной в две линии на подветренной стороне ядра под швом: юбка садится на неё и не проскакивает.
5. **Этажи ядра** — плоскость поперёк оси; на ступице буртик заднего этажа входит в выточку переднего; ось 8 мм центрирует;
   лопасти стыкуются встык на клею, юбки перекрывают этот стык и связывают этажи.
6. **Порядок сборки**: задний этаж → передний этаж → юбки спереди вдоль оси.

## 5. Развилки владельцу

- Предел 5 деталей со сборкой вдоль оси — 280–300 мм на Ender 3 (а не 340 мм геометрически); дальше юбка режется на два
  сегмента (8 деталей до 440 мм). Сегмент к сегменту — такая же гребёнка, сделанная в координатах лопасти.
- Шаг и глубина зубцов, угол хвоста — значения по умолчанию `[AI]` до пробной печати: шаг 20 мм, глубина 6 мм, угол 15°.
