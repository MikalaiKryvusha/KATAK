## 1. Устройство: Liam F1 и малые версии

### 1.1 Что это такое

- Горизонтально-осевая турбина с **тремя спиральными лопастями**, смещёнными на **120°** вокруг вала. Kim et al. описывают форму каждой лопасти как «похожую на треугольную пирамиду» [1]. Ротор конический: узкий «нос» обращён к ветру, широкий открытый торец (выход) — вниз по потоку. Угол раскрытия (opening angle) определяется на выходе как угол между осью и кромкой лопасти [4][9].
- По описанию изобретателя, лопасть получается из плоской заготовки: участок плоскости между окружностью радиуса R и плоской спиралью одновременно **закручивают и растягивают** вдоль оси [19].
- Ротор использует и подъёмную силу, и сопротивление [1][4]. Jang et al. классифицируют его как горизонтально-осевую турбину **сопротивления** (drag type) [3]. По этой причине теорию BEM к нему применять нельзя, и все расчёты сделаны через CFD [3].
- Флаер называет ротор самозапускающимся и без активного рыскания («yawing by rotorshape») [20]. Kim et al. объясняют пассивное рыскание силой сопротивления [1]. Брошюра AWM сравнивает турбину с флюгером, а в перечне деталей есть токосъёмное кольцо (slip-ring) [21].

## 2. Аэродинамика

### 2.1 Базовые соотношения

- Мощность ротора: **P = ½·ρ·A·V³·Cp**, где A = πR² — ометаемая площадь (так определяют все цитируемые работы [3][5][8]).
- Быстроходность: **λ = ω·R/V = π·n·D/(60·V)**, n в об/мин [5].
- Коэффициент момента: **Cq = Q/(½·ρ·A·V²·R) = Cp/λ** (в части работ обозначается Ct или CM — проверяйте определение [8][9]).
- Коэффициент тяги: **Ct = T/(½·ρ·A·V²)** [5].
- Предел Бетца: Cp ≤ 16/27 ≈ 0,593 [4][6].

**Расхождение производитель ↔ независимые данные.** Производитель заявляет Cp лопастей «52 %» и «88 % от Бетца» [19][20], а также «около 35 %» [21]. Независимые эксперименты дают 0,10–0,15 для ранних моделей [2][19] и 0,20–0,30 в стендовых работах египетских групп [10][11][12]. CFD-работы — 0,20–0,31. Работы с наибольшими CFD-значениями (Kim 2014, Jang 2019) написаны с участием производителя или его корейского партнёра [1][3]. Объяснение «52 %» изобретатель не публиковал, кроме заявления о многократной проверке на блокировку трубы [19]. Для калькулятора принимаю **Cp_max ≤ 0,31 как физически подтверждённый потолок** (оптимизированная CFD-геометрия [8][12]).

### 2.3 Почему у ASWT низкая быстроходность и большая тяга

- По форме ротор близок к «тупому телу»: у него большая смоченная площадь, и он отклоняет поток почти на 90° [19]. Kim et al. прямо называют большую тягу главным недостатком по сравнению с пропеллерной турбиной [1].
- Основную работу совершают периферийные участки: максимальный перепад давления у кромки лопасти [1][4]. Поэтому зона у оси (ступица, нос) почти не влияет на Cp. Это важно для раздела 6.8.

### 2.4 Рекомендуемая аппроксимация Cp(λ) для кода

**Форма: параболический Cp, то есть линейно убывающий момент.**

```
x      = λ / λ_opt
Cp(λ)  = Cp_max · x · (2 − x),        0 ≤ λ ≤ λ_run = 2·λ_opt   (иначе Cp = 0; за λ_run — отрицательный момент)
Cq(λ)  = Cp/λ = Cq0 · (1 − λ/λ_run),  Cq0 = 2·Cp_max/λ_opt       (коэффициент стартового момента)
```

**Обоснование.** Пересчёт таблицы моментов Mihalik et al. для трёхлопастного ротора (D = 0,25 м, V = 5 м/с) [6] даёт Cp = 0,109 / 0,191 / 0,245 / 0,271 / 0,264 при λ = 0,5 / 1,0 / 1,5 / 2,0 / 2,5 [РАСЧЁТ: Cp = M·ω/(½ρAV³)]. Cq здесь почти точно линеен по λ. Регрессия: **Cq0 = 0,246, наклон 0,0554 → λ_run = 4,43, λ_opt = 2,22, Cp_max = 0,272**. Парабола воспроизводит все пять точек с ошибкой ≤ 0,003 [РАСЧЁТ]. Предложенная в задании форма `Cp_max·x·exp(1−x)` хуже: она завышает Cp при малых λ (0,139 против 0,109 при λ = 0,5) и не даёт конечной разгонной λ [РАСЧЁТ]. Поэтому её не рекомендую.

### 2.5 Коэффициент тяги Ct (для прочности)

Данные:
- Ct монотонно убывает с ростом λ; больший угол раскрытия даёт больший средний Ct [5].
- Ct ≈ 0,68 при λ = 1,5 для ротора 30-45-60 с D = 0,25 м [5] (сеточная проверка: 0,673 / 0,677 / 0,680).
- Ct ≈ 0,66 (60-60-60) и ≈0,77 (30-55-60) при λ = 2, V = 10 м/с [РАСЧЁТ из Fx = 4,11 / 4,78 Н [7]: Ct = Fx/(½ρπR²V²)].
- Максимум осевой силы приходится на λ ≈ 0,5 [4].
- «Коэффициент сопротивления ≈ 0,9» по CFD, режим не указан [19] **[ПРОИЗВ.]**.
- Оптимизации с целью снизить тягу дают −8…−10 % при росте Cp [8][15][16].

**Модель для кода [ОЦЕНКА, огибающая сверху]:**

```
Ct(λ) = clamp(1.00 − 0.15·λ, 0.35, 1.00)
```

Значения: 0,775 при λ = 1,5 (данные 0,68) и 0,70 при λ = 2 (данные 0,66–0,77). Для угла выхода больше 60° добавлять **+10 % [ОЦЕНКА]**. Для прочностного расчёта в работе брать **Ct_design = 1,0** при скорости срабатывания тормоза.

### 2.6 Самоориентация по ветру: почему работает

- Источники: рыскание пассивное, «за счёт силы сопротивления» [1]; ротор «почти как флюгер», в деталях есть узел рыскания и токосъёмное кольцо [21]; «yaw control: none, yawing by rotorshape» [20].
- Механизм: у ASWT большой Ct (≈0,7–1,0) и большая боковая проекция конического корпуса. Если центр давления ротора лежит **по потоку за осью рыскания**, при отклонении γ возникает восстанавливающий момент M ≈ F_side(γ)·l, как у флюгера. Пропеллерной турбине для этого нужен хвост, у ASWT роль хвоста играет сам ротор. Механизм — **[ОЦЕНКА]**, качественно соответствует [1][21].
- Асимметрия: обороты при одном и том же угле зависят от направления отклонения, максимум при 15° по часовой стрелке [17]. Значит, равновесное положение рыскания, скорее всего, смещено на несколько градусов из-за закрутки следа и гироскопических эффектов. Это мой вывод **[ОЦЕНКА]**.
- Правила для калькулятора **[ОЦЕНКА]**:
  - плечо от оси рыскания до центра давления ротора l ≥ 0,3·D (центр давления брать в ≈2/3 длины ротора от носа);
  - подшипник рыскания с малым трением;
  - токосъём или ограничитель закрутки кабеля [21];
  - потерю мощности при отклонении считать как cos²γ (типично для горизонтальных турбин). Данных для ASWT нет.

### 3.1 Плотность воздуха

Стандартная атмосфера в тропосфере [36]:

```
T_ISA(h) = 288.15 − 0.0065·h                       [K], h — высота над уровнем моря, м
p(h)     = 101325 · (1 − 0.0065·h/288.15)^5.25588  [Pa]
ρ        = p / (R_d · T),   R_d = R*/M0 = 8314.32/28.9644 = 287.05 J/(kg·K)
```

Если пользователь задаёт фактическую температуру T, в последней формуле подставлять её вместо T_ISA. Контроль [РАСЧЁТ]: 0 м — 1,225; 500 м — 1,167; 1000 м — 1,112; 2000 м — 1,007 кг/м³. Влажность снижает ρ не больше чем на 1–2 % **[ОЦЕНКА]**; ею можно пренебречь.

### 3.2 Профиль скорости по высоте

**Логарифмический закон (основной, нейтральная стратификация)** [38]:

```
V(z) = V_ref · ln((z − d)/z0) / ln((z_ref − d)/z0)
```

Здесь d — высота вытеснения. Для городской застройки d ≈ 0,7 × средней высоты препятствий **[ОЦЕНКА]**; на открытой местности d = 0.

**Степенной закон (Хеллман):** V(z) = V_ref·(z/z_ref)^α. Показатель α, эквивалентный логарифмическому профилю: α = ln[ln(z/z0)/ln(z_ref/z0)]/ln(z/z_ref) [РАСЧЁТ — выводится из двух формул]. В [3] для ровной местности взято α = 1/7.

### 3.3 Распределение Вейбулла и Рэлея

```
f(v) = (k/c)·(v/c)^(k−1)·exp(−(v/c)^k)          [39]
c    = V̄ / Γ(1 + 1/k)                            [39]
E[v³] = c³·Γ(1 + 3/k)                            (момент распределения Вейбулла [39])
Рэлей (k = 2): c = 2·V̄/√π,  E[v³] = (6/π)·V̄³ ≈ 1.91·V̄³   [РАСЧЁТ]
```

По умолчанию k = 2. Если известно стандартное отклонение σ: k ≈ (σ/V̄)^−1.086 — эмпирика Justus (1978), по первоисточнику в этой работе **не проверена**. Типичный диапазон k для континентальных площадок 1,5–2,5 **[ОЦЕНКА]**.

### 3.4 Годовая выработка (AEP): алгоритм

```
для v от 0 до 40 м/с с шагом Δv = 0.1:
    если v < V_in или v ≥ V_out (с гистерезисом V_restart): P_el = 0
    иначе:
        λ   = λ_opt (идеальный MPPT) или λ из равновесия момента ротора и нагрузки (см. 4.2)
        P_a = ½·ρ·A·v³·Cp(λ)
        P_a = min(P_a, P_rated_mech)        // ограничение оборотов или мощности контроллером
        P_el = η_chain(P_a, n)·P_a           // см. 4.5
    AEP += P_el · f(v_hub) · Δv · 8760 h
CF = AEP / (8760 · P_rated_el)
```

Логика отсечек: у AWM включение 3 м/с, номинал 12,5 м/с, отключение 14 м/с [21]. Тормоз срабатывает примерно при 15 м/с и отпускается при 10 м/с, то есть с гистерезисом [19]. Контроллер ограничивает обороты [19]. В модели ASWT без управления шагом лопастей мощность выше номинала держится постоянной за счёт электрической нагрузки, то есть торможения [19][21]. Скорость включения рассчитывать по стартовому моменту (4.2).

### 3.5 Турбулентность, крыша и снижение выработки

Данные:
- **Warwick Wind Trials (2007–2008):** 26 турбин на зданиях, около 169 тыс. часов. Средний коэффициент использования **0,85 %** с учётом простоев и **4,15 %** без них. Выработка составила **5–10 %** от заявлений производителей [34].
- **Energy Saving Trust (2009):** на всех площадках на зданиях средняя скорость была **< 4 м/с**, и ни одна установка не дала больше 200 кВт·ч за год. Отдельно стоящие турбины имели коэффициент использования около 19 % и вырабатывали примерно в 6 раз больше; методика оценки ветра для зданий систематически завышала скорость [35].
- Интенсивность турбулентности по IEC для малых турбин: I15 = 0,18 [32].

### 4.2 Момент, стартовый момент и скорость включения

- Момент на валу: **Q = P/ω = Cq(λ)·½·ρ·A·V²·R**.
- Стартовый момент: **Q0 = Cq0·½·ρ·A·V²·R**, где Cq0 ≈ 0,22–0,25 (0,246 [6]; максимум Cq 0,278 при λ = 0,25 для угла 40° [9]).
- **Скорость начала вращения:** V_start = √(Q_res/(Cq0·½·ρ·A·R)). Здесь Q_res — зубцовый момент генератора, трение уплотнений и подшипников, трение передачи **[РАСЧЁТ — следует из формулы]**.
- Пример Q0 при Cq0 = 0,24 [РАСЧЁТ]: D = 0,2 м — 4,2 мН·м при 3 м/с; D = 0,3 м — 14 мН·м; D = 0,4 м — 33 мН·м; D = 0,6 м — 112 мН·м.
  Шаговый двигатель NEMA17 со стопорным моментом порядка 10–30 мН·м **[ОЦЕНКА]** не стронет ротор 0,2–0,3 м при 3 м/с.
- **Скорость начала зарядки** без повышающего преобразователя: обороты, при которых ЭДС достигает напряжения батареи, n_min = (V_batt + 2·V_f)·Kv_eff. Отсюда V_charge = π·D·n_min/(60·λ_opt) **[РАСЧЁТ]**.
- Равновесие при прямом заряде батареи без MPPT: генератор с ЭДС, пропорциональной ω, и внутренним сопротивлением задаёт момент нагрузки Q_L(ω). Рабочую точку находить из Q_rotor(ω, V) = Q_L(ω). Зависимость Cq(λ) линейна, поэтому уравнение решается аналитически или парой итераций **[ОЦЕНКА — метод]**.

### 4.4 Передача

При D ≤ 0,6 м обороты на рабочих скоростях 170–1400 об/мин (таблица 4.1), поэтому **прямой привод** на многополюсный BLDC или аксиальный генератор предпочтителен. Передача добавляет трение (растёт Q_res в формуле V_start) и потери. Если передача всё же нужна, брать зубчатый ремень GT2/HTD с передаточным числом 1:2…1:4 и КПД 0,95–0,98 на ступень **[ОЦЕНКА]**. Червячные передачи исключить: они необратимы или имеют низкий КПД **[ОЦЕНКА]**.

| Трёхфазный диодный мост, кремний (V_f ≈ 0,7–1,0 В на диод) | потери ≈ 2·V_f/V_dc: при 12 В — 12–17 % |
| Тот же мост на диодах Шоттки (V_f ≈ 0,3–0,5 В) | 5–8 % при 12 В |
| Активный (MOSFET) выпрямитель | 1–2 % |
| MPPT, повышающий или понижающий DC-DC | 85–95 % при средней нагрузке; < 70 % при загрузке < 10 % |
| Аккумулятор, цикл заряд-разряд | Li-ion ≈ 90–95 %, свинцово-кислотный ≈ 75–85 % |
| Провода | ≤ 2–3 % (цель проекта) |
| **Итог для самодельной системы** | **30–65 %** |

**Модель для кода:**

```
η_chain(n) = interp(n/n_rated, [0.15, 1.0], [0.34, 0.80])   // форма — по данным [3]; перенос на другой масштаб — [ОЦЕНКА]
P_el = max(0, η_chain · P_a − P_idle)                       // P_idle — потребление контроллера, 0.1–0.5 Вт [ОЦЕНКА]
```

## 5. Конструкция под 3D-печать

### 5.1 Нагрузки

**Классы малых ветроустановок IEC 61400-2** (по пересказу в [32]):

| Класс | Vref, м/с | Ve50 = 1,4·Vref, м/с |
|---|---|---|
| I | 50 | 70 |
| II | 42,5 | 59,5 |
| III | 37,5 | **52,5** |
| IV | 30 | 42 |

- Среднегодовые скорости для классов I–III: 10 / 8,5 / 7,5 м/с. Для класса IV в пересказе опечатка («0»); по стандарту, насколько мне известно, 6 м/с — **проверить по тексту стандарта** [32][33].
- Экстремальные скорости: Ve50 = 1,4·Vref·(z/z_hub)^0,11 и Ve1 = 0,75·Ve50 [32].
- Брошюра AWM считает статическую нагрузку именно для 52,5 м/с, то есть для класса III [21] (см. ниже).

**Расчётные случаи для ASWT:**

1. **Работа, максимальная тяга.** IEC, случай D: F_x,shaft = C_T·½·ρ·(2,5·V_ave)²·πR² = C_T·3,125·ρ·V_ave²·πR², где C_T = 0,5 для пропеллерных турбин [32]. **Для ASWT C_T = 0,5 занижен.** Брать F_op = Ct_design·½·ρ·A·V_brake², Ct_design = 1,0 (раздел 2.5) **[ОЦЕНКА на основе 5][7][1]**.
2. **Стоянка при экстремальном ветре.** IEC, случай H, ротор неподвижен: F_x,shaft = ½·B·Cd·ρ·Ve50²·A_proj,B, где **Cd = 1,5**; для вращающегося на холостом ходу ротора отдельная формула через λ_e50 [32].
   - У ASWT лопасть с одним оборотом и линейным ростом радиуса проецируется на фронтальную плоскость площадью πR²/3 [РАСЧЁТ]. Сумма по трём лопастям B·A_proj,B = πR² = A, хотя проекции частично перекрываются. Поэтому **F_park = ½·ρ·Ve50²·1,5·A**.
   - Производитель считает мягче: F = ½·ρ·V²·A_cross·Cd·G при ρ = 1,2754, V = 52,5 м/с, Cd = 0,9, порывном коэффициенте G = 1,5 и площади сечения 1,299 / 0,318 м². Получается **3082 Н для 1,5 м и 756 Н для 0,75 м** [21] (пересчёт сходится [РАСЧЁТ]). Эквивалентно Cd·G·A_cross/A ≈ 0,99 против 1,5 по IEC.
   - Примеры по IEC при Ve50 = 42 / 52,5 м/с [РАСЧЁТ]: D = 0,2 м — 51 / 80 Н; 0,3 м — 115 / 179 Н; 0,4 м — 204 / 318 Н; 0,6 м — 458 / 716 Н; 1,0 м — 1273 / 1989 Н.
   - Для сравнения: при работе на 20 м/с с Ct = 0,95 тяга всего 16 Н для D = 0,3 м. **Определяющий случай — стоянка.**
3. **Максимальные обороты** (IEC, случай E): центробежная сила лопасти F_z = m_B·ω_max²·R_cog [32].
4. **Короткое замыкание генератора** (IEC, случай F): M_x,shaft = G·Q_design, G = 2, если нет данных [32]. Для печатных ступиц важна фиксация от проворота на валу.
5. **Рыскание** (IEC, случай B) — гироскопические нагрузки при быстром повороте [32]; для ASWT формулы не адаптированы.

### 5.2 Центробежные напряжения и разнос

- Тонкое свободное кольцо (кромка выхода, если сделан обод): **σ_θ = ρ_m·ω²·r² = ρ_m·v_tip²**. Напряжение не зависит от размера, только от скорости кромки (классический результат для вращающегося кольца).
- Радиальный стержень постоянного сечения от оси до R (грубая модель лопасти, работающей на растяжение к ступице): **σ_root = ρ_m·ω²·(R² − r_h²)/2 ≈ ρ_m·v_tip²/2**.
- PLA, ρ_m = 1240 кг/м³ [40] [РАСЧЁТ]:

| v_tip | Кольцо | Стержень |
|---|---|---|
| 30 м/с | 1,1 МПа | 0,6 МПа |
| 60 м/с | 4,5 МПа | 2,2 МПа |
| 100 м/с | 12,4 МПа | 6,2 МПа |
| 132 м/с | 21,6 МПа | 10,8 МПа |

  При Z-прочности PLA 35 МПа [40] и запасах IEC (5.5) разнос до v_tip ≈ 100 м/с **недопустим**.
- **Свидетельство из практики:** модель Peutz разрушилась при 21 м/с от центробежных сил балансировочных грузов на внешнем кольце; первый прототип разрушился в трубе при 7 м/с [19]. Отсюда правила:
  - не ставить массу на периферии;
  - ограничивать обороты электрическим торможением (замыкание фаз через резисторы) с порогом **n_brake ≤ 1,2·n(λ_opt, V_out)** **[ОЦЕНКА]**;
  - проверять σ при v_tip = λ_run·V_brake.

### 5.3 Вал: изгиб с кручением

Обозначения: M — изгибающий момент в опасном сечении (обычно у переднего подшипника: M = F_x·a_cp + m_rotor·g·a_cg, где a — вылет), T — крутящий момент, n — запас, S_y — предел текучести.

```
Сплошной, теория наибольших касательных (Треска):  d   = [ 32·n/(π·S_y) · √(M² + T²) ]^(1/3)
Сплошной, энергетическая (фон Мизес):              d   = [ 32·n/(π·S_y) · √(M² + 0.75·T²) ]^(1/3)
Полый, k = d_i/d_o:                                d_o = [ 32·n/(π·S_y·(1 − k⁴)) · √(M² + ...) ]^(1/3)
Через допускаемое касательное напряжение:          d_o = [ 16/(π·τ_allow·(1 − k⁴)) · √(M² + T²) ]^(1/3)
```

Источники формул [50][51]: эквивалентный крутящий момент √(M² + T²) и множитель (1 − k⁴) для полого вала. С коэффициентами ударности по ASME: √((K_m·M)² + (K_t·T)²) [50][51]. У ASWT T мал по сравнению с M на стоянке, поэтому **вал рассчитывается на изгиб**.

**Пример [РАСЧЁТ]:** D = 0,3 м, F_park = 115 Н, вылет 0,08 м → M = 9,2 Н·м, T ≈ 0.
- Сталь S_y = 250 МПа: d = 9,1 мм при n = 2 и **10,7 мм при n = 3,3** (γf 3,0 × γm 1,1 по IEC, 5.5).
- SUS304, S_y = 215 МПа (значение из [31]): 9,5 / 11,3 мм.
- Полый вал k = 0,6: d_o = 11,2 мм.
- Печатный вал из PLA (Z-прочность 35 МПа, n = 3) — уже 20 мм, к тому же PLA ползёт.

→ **Вал металлический** (нержавеющий пруток или резьбовая шпилька), ступица печатная. Для D ≈ 0,3 м — 10–12 мм. Ориентир крупного масштаба: для лопастей 1,5 м класса в FSI-работе рассматривали вал SUS304 диаметром 20–40 мм [31].

### 5.8 Спицы и связи между лопастями и ступицей

Источники:
- в серийном роторе поперечные стальные связи предотвращают вибрации и взаимные колебания лопастей [6];
- влияние стяжек между лопастями изучали в FSI- и модальном анализе литых лопастей 750 мм из стеклонаполненного PP [30];
- кольцо с массой на периферии стало причиной разрушения [19].

Рекомендуемая схема **[ОЦЕНКА]**:
1. **Меридиональные стяжки.** В меридиональной полуплоскости три лопасти пересекаются почти параллельными отрезками (6.2). Один стержень, лежащий в этой плоскости поперёк образующих на радиусе 0,6–0,75R, проходит через все три лопасти. Ставить 3 таких стержня через 120°, смещённых на 60° от выходных концов лопастей: всего 9 узлов. Материал — углепластиковый пруток 2–4 мм или шпилька М3–М4 с печатными бобышками.
2. **Фланец ступицы** с пазами под корни лопастей; лопасть заходит в ступицу на ≥ 2t.
3. **Обод на выходе** (кольцо через три выходные кромки) — только при D ≥ 0,4 м, лёгкий: проверка σ = ρv_tip² по 5.2.
4. Резонанс: первая собственная частота лопасти должна быть выше 3·n_max/60. Для трёх лопастей возбуждение идёт на частотах 1P и 3P (по аналогии с горизонтальными турбинами) [ОЦЕНКА]. Модальную проверку делали в [30].

### 5.9 Ориентация печати

- Печатать с осью ротора вертикально. Тогда центробежная радиальная нагрузка лежит в плоскости слоя XY, то есть в сильном направлении [ОЦЕНКА].
- **Нависание ≈ α** (угол образующей от оси равен углу от вертикали) [РАСЧЁТ — геометрия]. У PLA Basic предел нависания 55° [40], поэтому при α_exit = 60–70° выходной зоне нужны древовидные поддержки или профиль с переменным углом.
- Лопасть больше стола печатать секциями по параметру u (раздел 6) с замком «ласточкин хвост» или штифтами [ОЦЕНКА].

## 6. Геометрия для CAD (параметрическая поверхность)

### 6.1 Как определяют лопасть в литературе

1. **Изобретатель** [19]: плоская заготовка между окружностью R и плоской спиралью одновременно закручивается и растягивается вдоль оси. Первый вариант — угол раскрытия 30° и «π оборотов», позднее — 1 оборот и ≈60°.
2. **Kim et al. / Lu et al.** [1]: параметры формы
   - α — угол между осью и кромкой лопасти;
   - R1 — радиус внешнего конца кромки;
   - R2 — радиус внутреннего конца;
   - S1 — осевое расстояние от переднего конца лопасти до её корня.
   Лопасть похожа на треугольную пирамиду, три лопасти через 120°.
3. **Sapkota et al.** [4]: спираль r = a + b·θ^(1/c), при c = 1 — архимедова. Шаг — осевое расстояние за полный оборот спирали. Угол раскрытия — угол выхода воздуха относительно набегающего потока.
4. **Song et al.** [5] и **Nawar et al.** [10]: углы α1, α2, α3 измеряются в одной меридиональной плоскости между осью и тремя «пересечениями» лопастей; α3 — у выходного конца первой лопасти. Если α1 = α2 = α3, тип «фиксированный», если углы растут к выходу — «переменный». Ступица 25 мм при D = 250 мм, t = 3 мм.
5. **Li, Li & Xu 2026** [8] — единственное явное аналитическое задание. Направляющая линия — пространственная спираль Архимеда:
   ```
   X(t) = a·t·sin t,  Y(t) = a·t·cos t,  Z(t) = b·t,  t ∈ [0, 2π·SRN],
   a = R/(2π·SRN),  b = B1H/(2π·SRN)
   ```
   Образующая — отрезок AB от точки A на оси к точке B, бегущей по спирали от B1 до B2. Угол раскрытия θ — угол AB2 к оси, тогда AH = R/tan θ. Проектные переменные: шаг (2πb), θ и SRN; R = 125 мм, t = 2 мм. Из текста **неоднозначно**, неподвижна ли точка A (коническая поверхность) или движется вдоль оси при постоянном угле. В модели KATAK есть оба режима.
6. **Dai et al.** [7]: D = 360 мм, **L/D = 0,90**, t = 4 мм, угол закрутки 0–360°, «углы раскрытия» трёх групп лопастей θ1–θ3, «фиксированный шаг» s = 96–126 мм, вал 35 мм. Здесь s, по-видимому, означает другое, чем шаг в [4][8]: осевой интервал между соседними лопастями. **Не смешивать определения.**
7. **Hamid & Abd El Maksoud** [9]: архимедова спираль r = a + b·t против логарифмической r = a·e^(bt). Угол раскрытия — между осью и кромкой лопасти на выходе, 40–90°; «три конические лопасти с треугольным основанием».

### 6.2 Единая параметрическая модель KATAK (мой синтез источников [1][4][5][8][19])

**Входные параметры:**

| Параметр | Смысл | По умолчанию |
|---|---|---|
| R = D/2 | наружный радиус | — |
| r_h | радиус ступицы | 0,1·R |
| N | число лопастей | 3 |
| n_t | число оборотов (SRN) | 1,0 |
| L_s | осевая длина внешней кромки; шаг P = L_s/n_t | 1,8·R (L/D = 0,9) для профиля 30-45-60; 1,6·R (L/D = 0,8) для фиксированного 60° |
| p | показатель роста радиуса кромки | 1 (архимедова спираль) |
| q | показатель осевого хода | 1 (постоянный шаг) |
| α(u) | закон угла раскрытия | постоянный или переменный (ниже) |
| h = ±1 | направление закрутки | — |
| t | толщина | по 5.7 |
| u | параметр вдоль закрутки, 0 — нос, 1 — выход | — |
| v | параметр вдоль образующей, 0 — ступица, 1 — внешняя кромка | — |

**Внешняя кромка лопасти k** (k = 0…N−1):

```
θ_k    = 2π·k/N                          // сдвиг 120° при N = 3
θ_o(u) = θ_k + h·2π·n_t·u
r_o(u) = r_h + (R − r_h)·u^p             // p = 1: r линейно по углу — архимедова спираль, как в [8]
z_o(u) = L_s·u^q                         // q = 1: z = b·t, как в [8]
```

**Закон угла раскрытия α(u):**
- фиксированный: α(u) = α_exit (60° по умолчанию [4][9]);
- переменный (по [5][7][11]): кусочно-линейный через точки (u = 1/3, α1), (2/3, α2), (1, α3) с постоянной экстраполяцией при u < 1/3. По умолчанию 30-45-60°; варианты 25-50-60 [11] и 30-55-60 [7]. При n_t = 1 эти точки совпадают с тремя пересечениями одной меридиональной плоскости, как в определении [5] [РАСЧЁТ].

**Корневая (ступичная) кромка — образующая под углом α(u) к оси в меридиональной полуплоскости θ = θ_o(u):**

```
режим «постоянный угол»: z_h(u) = z_o(u) − (r_o(u) − r_h)·cot α(u)
режим «вершина» ([8], A неподвижна): z_h(u) = z_A = L_s − (R − r_h)·cot α_exit
                                     α(u) = atan2(r_o(u) − r_h, z_o(u) − z_A)
```

**Поверхность лопасти S_k(u, v), u, v ∈ [0, 1]:**

```
θ(u,v) = θ_o(u)
r(u,v) = r_h + v·(r_o(u) − r_h)
z(u,v) = z_h(u) + v·(z_o(u) − z_h(u))
x = r·cos θ,  y = r·sin θ
```

Все меридиональные сечения — прямые отрезки, поверхность линейчатая. Это даёт «треугольную пирамиду» [1] и прямые линии с углами α1…α3 [5].

**Опции:**
- «Наутилус» — логарифмический рост: r_o(u) = r_h·(R/r_h)^u [9];
- p < 1 — быстрее раскрывается у носа;
- q ≠ 1 — переменный шаг.

**Проверки допустимости [РАСЧЁТ — следует из формул]:**
1. z_h(u) ≥ 0 и не убывает. При p = q = 1 и постоянном α это условие **L_s ≥ (R − r_h)·cot α**. Для 60° и r_h = 0,1R нужно L_s ≥ 0,52R, то есть L/D ≥ 0,26. Для переменного угла 30-45-60 при u ≤ 1/3 нужно L_s ≥ 1,56R (L/D ≥ 0,78). При нарушении — предупреждение и коррекция z_h(u) ← max(0, накопленный максимум z_h).
2. Зазор между соседними лопастями в меридиональной плоскости. При p = q = 1 линии соседних лопастей параллельны, сдвинуты по оси на Δz = (L_s − (R − r_h)·cot α)/(N·n_t), а перпендикулярное расстояние между ними **g = Δz·sin α**. Требование g − t ≥ 2t, иначе лопасти слипаются при печати и запирают поток.
   - Фиксированные 60°, L/D = 0,8: g ≈ 0,31R — с запасом.
   - Профиль 30-45-60 при L/D = 0,8: в носовой трети (α = 30°) g ≈ 0,007R, то есть лопасти почти касаются.
   - Вывод: для угла 30° у носа нужно **L_s ≥ 1,56R + 6·(N·n_t)·t**, то есть L/D ≈ 0,9 при R = 150 мм, t = 2,4 мм. Это совпадает с геометрией 30-55-60 при L/D = 0,9 из [7].
   - По умолчанию: **L/D = 0,9 для переменного профиля, 0,8 для фиксированного 60°** (Liam F1: 1,2/1,5 [3]).
3. При n_t > 1 проверять самопересечения (внешняя кромка не должна заходить внутрь соседней лопасти).

### 6.3 Толщина, сетка и STL

- Нормаль: n̂ = (∂S/∂u × ∂S/∂v)/|…|. Две поверхности S ± (t/2)·n̂ плюс боковые стенки по краям u = u0, u = 1, v = 0 и v = 1 дают замкнутое тело.
- При u = 0 образующая вырождается в точку (r_o = r_h), поэтому начинать с u0 ≈ 0,02 или задавать r_o(0) = r_h + t.
- Сетка: N_u ≈ 120·n_t, N_v ≈ 30 — для печати достаточно **[ОЦЕНКА]**.
- Лопасть заглублять в ступицу на ≥ t (объединение тел или пересекающиеся замкнутые оболочки — слайсер обработает).
- Ступица — цилиндр r_h от z = 0 до z_h(1) + фланец, с соосным отверстием под вал и шестигранным или D-образным посадочным местом.

### 6.4 Направление вращения

Для винтовой поверхности z ∝ h·θ под потоком вдоль +z давление на наветренную сторону даёт тангенциальную силу, направленную против h·θ [РАСЧЁТ: нормаль (h·c·sin θ, −h·c·cos θ, r), её проекция на e_θ равна −h·c]. **Ротор вращается в сторону, противоположную направлению закрутки внешней кромки при движении вниз по потоку.** Это определяет направление резьбы стопорной гайки: она не должна откручиваться при вращении.

### 6.8 Носовой обтекатель (отдельная печатная деталь)

**Что найдено в источниках:**
- В CFD-модели Kim et al. есть «конус ступицы» (hub cone): набегающий поток «блокируется конусом ступицы и ротором». За ступицей образуются зона рециркуляции и область пониженной скорости [1][2]. Вихрь у ступицы сильнее при больших углах раскрытия [5].
- В [3] выступающие болты и гайки ступицы при построении CFD-модели заменили «колпачком» (cap shape), чтобы избежать плохой сетки и паразитных вихрей. Значит, у реальной машины на носу есть крепёж, который разумно закрыть.
- **У серийного Liam F1/AWM переднего подшипника перед ротором, по-видимому, нет.** Изобретатель описывает переход от схемы «опора спереди и сзади» к креплению только сзади [19]. Генератор, тормоз, корпуса подшипников, муфта и токосъём расположены в раме за ротором [21]. В такой схеме обтекатель **не защищает подшипник** — тот находится за широким торцом ротора и требует отбойника или лабиринта (5.4).
- Обтекатели (spinner) у пропеллеров и турбин: «обтекаемый кожух над втулкой», снижает сопротивление и выравнивает поток [52]; служит защитным экраном ступицы [54]; на большинстве турбин мощности не создаёт [54]. У горизонтальных турбин радиальное растекание потока у ступицы «уводит ветер от лопастей» — на это направлены «мощностные обтекатели» [55]. Измеренного влияния носового обтекателя на Cp ни для ASWT, ни для малых горизонтальных турбин **не найдено**. Форумные оценки скептичны («внутренняя треть почти не работает») [56].
- Формы носовой части, x — от вершины, y — радиус, L — длина, R_b — радиус основания [53]:
  - конус: y = R_b·x/L;
  - эллипсоид: y = R_b·√(x·(2L − x))/L;
  - касательный оживал: ρ = (R_b² + L²)/(2R_b), y = √(ρ² − (L − x)²) + R_b − ρ;
  - степенной ряд: y = R_b·(x/L)^n, 0 ≤ n ≤ 1;
  - ряд Хаака (фон Карман при C = 0).

**Инженерная оценка роли обтекателя у ASWT [ОЦЕНКА]:**
1. Аэродинамика: площадь внутри r_h = 0,1R — всего 1 % ометаемой площади, а момент создаётся у периферии [1]. Поэтому влияние на Cp ожидаю **≤ 1–3 %**. Полезный эффект — гладкое начало трёх лопастей вместо тупого торца вала: меньше отрыв, свист и пульсации. Влияние на рыскание пренебрежимо.
2. Защита: закрывает торец вала, гайку и корни лопастей от воды, пыли, льда и коррозии. **Подшипник защищает только в схеме «неподвижная ось»**: ротор вращается на подшипниках, встроенных в собственную ступицу (мотор-колесо или ось через ротор). Тогда передний подшипник стоит прямо за носом, и обтекатель служит его крышкой. При креплении ротора консольно на вал, выходящий из генератора сзади, защищать подшипник нужно не носом, а отбойником на заднем торце.
3. Конденсат: не делать обтекатель герметичным. Нужно дренажное отверстие Ø 2–3 мм у основания, попадающее в нижнюю точку при любом угле поворота, — например кольцевая щель.

**Рекомендуемая геометрия для генератора STL [ОЦЕНКА]:**

| Параметр | Значение |
|---|---|
| Форма | эллипсоид (по умолчанию), касательный оживал или степенной ряд с n = 0,5–0,75; острый конус не рекомендую — отрыв на стыке |
| Радиус основания | R_b = r_h + (0…t): основание совпадает со ступицей, лопасти начинаются на нём |
| Удлинение L_nose/(2·R_b) | 0,6–1,0 (по умолчанию 0,8) |
| Стенка | 1,6–2,4 мм, 3–4 периметра, заполнение 15–20 % |
| Материал | ASA или PETG |
| Печать | вершиной вверх |
| Крепление | центрирующий хвостовик в отверстие ступицы, винт М3/М4 соосно с валом или байонет; накидная гайка, если ось резьбовая |
| Учёт в прочности | массу обтекателя включать в изгиб вала (5.3) |

Опционально — **хвостовой конус** за ступицей для уменьшения рециркуляции [1][5]. Эффект для ASWT не измерен.

1. Площадка: ρ(h, T), V_hub по логарифмическому закону, распределение Вейбулла, f_site.
2. Геометрия → множители → Cp_max, λ_opt, Ct(λ).
3. Мощность P(V) с ограничениями V_in, V_rated, V_out.
4. η_chain → P_el(V), AEP, коэффициент использования.

7. Геометрия → STL: лопасти, ступица, стяжки, нос.
