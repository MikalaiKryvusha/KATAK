## Зачем это KATAK

Генератор должен выдавать толщины, которые слайсер кладёт **целым числом линий** (слово владельца: «генерировать удобные
толщины»), детали не тоньше, чем печатает сопло, и посадки, которые собираются. Для этого нужны три числа от
пользователя — **диаметр сопла d**, **высота слоя h**, **слайсер** — и правила ниже.

## 1. Ширина линии экструзии w

| Слайсер | Что по умолчанию | Источник |
|---|---|---|
| PrusaSlicer | ширина 0 → берётся **1,125 × d** (сопло 0,4 → 0,45 мм); внешний периметр в старом Slic3r — 1,05 × d | [Prusa: профили для разных сопел](https://help.prusa3d.com/en/article/creating-profiles-for-different-nozzles_127540) · [Slic3r manual, flow math](https://manual.slic3r.org/advanced/flow-math) |
| OrcaSlicer | ширина задаётся в мм или в % от d; ориентиры wiki: внешняя стенка 105–120 %, сплошное заполнение ≈ 110 %, мосты ≈ 100 % | [OrcaSlicer wiki: line width](https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_line_width) |
| Cura | ширина линии по умолчанию равна d | (документация Cura — не открывалась в этой разведке; число требует проверки) |

**Решение для KATAK `[AI]`:** по умолчанию w = 1,125 × d (как PrusaSlicer); поле «ширина линии» можно поменять — тогда
расчёт стенок идёт от неё.

## 2. Толщина стенки из N линий — математика потока

Slic3r (и наследники: PrusaSlicer, OrcaSlicer) считают сечение линии прямоугольником со скруглёнными краями; соседние
линии перекрываются, и шаг между их осями ([Slic3r manual, flow math](https://manual.slic3r.org/advanced/flow-math)):

```
spacing = w − h · (1 − π/4)
```

Отсюда толщина стенки из N линий (одна полная ширина + N−1 шагов; формула с форума Prusa, выводится из формулы мануала):

```
T(N) = w + (N − 1) · spacing = N·w − (N − 1) · h · (1 − π/4)
```

Пример: сопло 0,4, w = 0,45, h = 0,2 → spacing = 0,407 → T(1) = 0,45 · T(2) = 0,857 · T(3) = 1,264 · T(4) = 1,671 мм.

**Правило генератора `[AI]`:** просимая стенка T₀ — минимум. KATAK берёт наименьшее N ≥ 2, при котором T(N) ≥ T₀, и
генерирует ровно T(N); на странице показывает «T(N) мм = N линий». (Сначала было «ближайшее T(N)»: при T₀ = 1,0 оно давало
0,857 мм — тоньше просимого, а стенка тоньше плана слабее, чем пользователь рассчитывал.)

## 3. Arachne — переменная ширина линии

PrusaSlicer (и Cura, и OrcaSlicer) умеют генератор периметров **Arachne**: он меняет ширину линии внутри диапазона и
закрывает «неудобные» толщины. Настройки, которые важны генератору ([Prusa: Arachne](https://help.prusa3d.com/article/arachne-perimeter-generator_352769)):

- **Minimum feature size** — элементы тоньше этого не печатаются вовсе;
- **Minimum perimeter width** — тонкий элемент расширяется до этой ширины;
- для функциональных деталей, где важна точность вогнутых углов, Prusa советует классический генератор.

Вывод (слово владельца — `ideas/03`): Arachne — страховка слайсера. KATAK всё равно генерирует T(N) — это печатается ровно
и быстро и в классическом режиме, и в Arachne.

## 4. Высота слоя h

- Рабочий диапазон — **25–75 % от d**; 50 % — частая отправная точка; Cura предупреждает выше 80 %
  ([Fast Radius](https://fastradius.com/why-3d-printing-layer-height-matter/) · [Polymaker wiki](https://wiki.polymaker.com/the-basics/3d-slicers/quality-layer-height) · [3DPrinterly](https://3dprinterly.com/which-layer-height-is-best-for-3d-printing/)).
- Сопло 0,4 → 0,1–0,3 мм, по умолчанию 0,2.

**Правило `[AI]`:** KATAK предлагает h = 0,5 · d (округлённо до 0,02) и предупреждает, если h вне 25–75 % d.

## 6. Посадки (вал, подшипник, нос на ступицу)

- Отверстия FDM печатаются **меньше** модели, наружные поверхности — чуть больше
  ([Sovol: допуски FDM](https://www.sovol3d.com/blogs/news/fdm-3d-printing-tolerances-clearances-how-to-design-parts-that-fit)).
- Скользящая посадка: ≈ 0,15–0,4 мм зазора по диаметру в зависимости от принтера
  ([UAL wiki](https://wiki.cci.arts.ac.uk/books/digital-fabrication-lab/page/design-the-clearance-and-tolerance) ·
  [U-Michigan / Hubs](https://dozuki.umd.edu/Guide/Tolerancing/306)).
- Прессовая посадка — самая разнобойная категория: от −0,05 до +0,2 мм; все источники советуют напечатать пробник.
- Связь зазора с диаметром сопла источники **не устанавливают** — это проверяется на своём принтере.

**Правило `[AI]`:** поле «зазор посадки» с умолчанием 0,3 мм (скользящая) и 0,1 мм (прессовая под подшипник); KATAK
может сгенерировать маленький STL-пробник с несколькими зазорами — идея на будущее, не в первой версии.
